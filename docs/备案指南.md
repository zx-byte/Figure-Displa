# 小程序 ICP 备案指南

2023 年 9 月起，微信小程序**必须完成 ICP 备案才能上架**。没备案的小程序可以开发、可以预览，但提交审核会被拒。

纯展示模式有个好处：**个人主体就能备案**，不需要营业执照。但备案时怎么描述小程序用途，直接决定能不能过——这一点下面单独讲。

---

## 一、先确认你能不能备

| 主体类型 | 能不能备 | 限制 |
| --- | --- | --- |
| 个人 | 能 | 服务内容不能涉及经营性活动（销售、支付、会员收费） |
| 个体工商户 | 能 | 需营业执照 |
| 企业 | 能 | 需营业执照、法人信息 |

你当前是纯展示 + 微信联系定制，没有线上交易，**个人主体完全符合**。

但要注意：小程序名称、简介、页面内容、备案填写的服务内容，四者必须一致。如果页面上写着价签和「购买」，备案却填「作品展示」，管局可能驳回。这也是前面把「立即购买」改成「微信咨询定制」的原因之一。

---

## 二、材料清单

个人主体需要准备：

| 材料 | 要求 |
| --- | --- |
| 身份证 | 正反面照片，清晰、四角完整、不反光 |
| 手机号 | 需与身份证实名一致，能接收验证码 |
| 邮箱 | 常用邮箱，用于接收备案通知 |
| 小程序信息 | 名称、简介、服务类目（已在注册时填过） |
| 应急联系人 | 部分省份要求填写，可填家人 |

不需要：营业执照、公章、场地证明、域名证书。

---

## 三、操作步骤

### 1. 进入备案入口

登录 [mp.weixin.qq.com](https://mp.weixin.qq.com)（小程序管理后台）→ 左侧菜单 **设置 → 基本设置** → 找到「小程序备案」→ 点击「去备案」。

如果找不到，首页通常会有备案提示的横幅，直接点进去。

### 2. 填写主体信息

按提示填姓名、身份证号、证件有效期，上传身份证正反面。

部分省份会要求**人脸核验**（微信扫脸），准备好光线充足的环境。

### 3. 填写小程序信息

这是最关键的一步，见下一节。

### 4. 微信初审

提交后微信会先审一遍，通常 1–3 个工作日。有问题会退回让你改。

### 5. 管局审核

微信初审通过后自动提交到**你所在省的通信管理局**，这步最耗时，1–20 个工作日不等。

审核结果通过短信和邮件通知。

### 6. 拿到备案号

通过后，小程序「更多资料」页会自动显示备案号，你不需要手动展示。

---

## 四、服务内容怎么填（最容易翻车的地方）

备案时要选择服务类目并填写备注说明。**填错这一项，个人主体大概率被驳回。**

### 类目选择

| 推荐 | 避免 |
| --- | --- |
| 文娱 → 其他 | 电商平台 |
| 生活服务 → 其他 | 商家自营 |
| 图片 → 图片展示 | 网络购物 |

### 备注说明怎么写

对比一下：

| ❌ 会被驳回的写法 | ✅ 能通过的写法 |
| --- | --- |
| 手办销售商城，提供在线选购与支付服务 | 个人手工作品的图片展示与制作过程分享 |
| 出售原创手办模型，支持在线下单 | 展示手作人原创作品，供爱好者浏览欣赏 |
| 手办电商平台，提供交易与定制服务 | 作品陈列页面，定制需求通过微信沟通 |

**核心原则**：描述「展示」和「分享」，不要出现「销售」「交易」「支付」「下单」「商城」。

这和代码里的改动是一套逻辑——页面上没有交易入口，备案描述才能站得住。

## 五、时间线

| 阶段 | 耗时 |
| --- | --- |
| 填写材料 | 30–60 分钟 |
| 微信初审 | 1–3 个工作日 |
| 管局审核 | 1–20 个工作日（各省差异大） |
| **合计** | **通常 1–4 周** |

管局审核速度取决于省份。江苏、浙江、广东通常较快，部分省份偏慢。

**这段时间小程序可以正常开发和预览，只是不能提交审核发布。**

---

## 六、常见驳回原因

| 原因 | 怎么改 |
| --- | --- |
| 服务内容含经营性表述 | 参照第四节改写成「展示」「分享」 |
| 小程序名称与备案内容不符 | 名称里含「商城」「旗舰店」的，考虑改名 |
| 身份证照片不清晰、有反光 | 重拍，白底、光线均匀 |
| 手机号与身份信息不一致 | 用本人实名认证的手机号 |
| 小程序简介与实际内容不符 | 把简介改成与页面一致 |
| 类目选择与内容不匹配 | 选「文娱-其他」或「生活服务-其他」 |
| 应急联系人信息不完整 | 补全，确保电话能接通 |

---

## 七、备案通过之后

1. 回到小程序后台提交审核（版本管理 → 提交审核）
2. 审核通过后点击「发布」
3. 发布后，We分析的埋点数据才开始统计
4. 微信搜索里能搜到你的小程序

---

## 八、几个实务提醒

**备案是一次性的，不需要年审。** 但主体信息变更（比如改名字、换手机号）要更新备案。

**一个身份证可以给多个小程序备案**，但同一时间可能有数量限制，具体以提交时提示为准。

**备案不收费。** 任何声称"代办备案收费"的服务，本质上只是帮你填表。自己填 30 分钟，没必要花钱。

**备案期间别改小程序名称。** 名称变更会导致备案信息不一致，需要重新提交。
