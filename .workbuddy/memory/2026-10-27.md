## 作品导入流水线（用户：把小红书主页「红糖」的手办放进小程序）

用户提供小红书主页链接，要求把上面的手办放进小程序。经确认：**别人的账号，已获授权**，
图片由用户自己下载到文件夹。

### 抓取能力边界（重要，后续别再白试）
- 小红书主页静态抓取只能拿到文字（昵称/笔记标题/点赞数），**拿不到封面图地址**——
  必须登录态，curl 会被 302 到登录页。
- 本机无浏览器控制扩展（Chrome Extensions 目录为空），无法自动化带登录态取图。
- 连接器市场无「指定博主主页取图」能力（只有选品/舆情/设计类）。
- 结论：图片必须用户手动下载提供。

### 新增能力
- `scripts/import-works.js`：扫描 `miniprogram/images/works/`，按文件名前缀分组为作品，
  读 `作品原图/红糖/作品信息.json` 元信息，生成 `miniprogram/config/works.js`，
  并输出 `output/works-seed.json`（云数据库上线用种子）。
- `miniprogram/config/works.js`：自动生成的作品数据模块（初始为空数组）。
- `mock.js`：`PRODUCTS = WORKS.concat([...演示商品])`，真实作品 sort 从 900 递减排最前。
- 分组规则：`作品名-01.jpg` / `作品名-02.jpg` → 同一件作品，序号最小的作封面；
  `-`/`_`/空格均可作分隔符；末尾 1~3 位数字识别为序号。
- 元信息支持 `defaults` 全局兜底 + `works` 单件覆盖；缺失时按默认值生成不报错；
  元信息键无对应图片会告警。

### 「询价」展示（纯展示形态的必要配套）
作品常不标价，原逻辑显示 ¥0.00。改为 `price <= 0` 显示「询价」：
- `goods-card`：新增 `inquire` 标志 + `.price--inquire` 样式
- `detail`：同样处理 + `.price-main--inquire` 样式（52rpx → 36rpx）

### 环境坑
- Pillow 本机未装，`pip install` 在沙箱内会挂起（PyPI/镜像都被拦），
  **必须 `dangerouslyDisableSandbox` 才能装上**。清华镜像在沙箱外 HTTP 200。
- `compress-images.py` 支持把子目录当源：`python scripts/compress-images.py 作品原图/红糖`
  （内部用 `os.listdir`，需图片直接放在该目录下）。
